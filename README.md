# Bài thực hành PHP - Phạm Hưng (22001598)

Repository bài thực hành học phần. Mỗi buổi được lưu trong một thư mục riêng.

## Buổi 2 - Function & OOP

- `Bai1_GioHang/index.php`: quản lý giỏ hàng bằng `CartItem` và `ShoppingCart`.
- `Bai2_QuanLyVeXemPhim/index.php`: quản lý phim, đặt/hủy vé và các hàm xử lý danh sách phim.

### Chạy bài

Yêu cầu PHP CLI. Mở terminal tại thư mục repository và chạy:

```bash
php "Buoi 2/Bai1_GioHang/index.php"
php "Buoi 2/Bai2_QuanLyVeXemPhim/index.php"
```

Hai bài chạy độc lập và không cần framework.
